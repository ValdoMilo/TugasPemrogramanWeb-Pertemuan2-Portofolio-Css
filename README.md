# Portofolio Pribadi (Enhanced with CSS) - Tugas Pemrograman Web (Pertemuan 2)

Repository ini berisi *source code* untuk tugas mata kuliah Pemrograman Web pada pertemuan kedua. Proyek ini merupakan kelanjutan dan pengembangan dari tugas pertemuan pertama, di mana fokus utamanya adalah memperindah dan mengatur tata letak halaman portofolio menggunakan teknik Cascading Style Sheets (CSS) yang lebih mendalam.

## 📝 Deskripsi Proyek

Proyek ini bertujuan untuk menerapkan konsep-konsep *styling* dasar hingga menengah pada struktur HTML yang sudah dibuat sebelumnya. Melalui tugas ini, tampilan halaman web portofolio yang tadinya kaku menjadi lebih modern, terstruktur, dan memiliki nilai estetika yang lebih baik.

## ✨ Peningkatan dan Fitur Baru (Fokus CSS)

* **Pemisahan File (External CSS):** Kode CSS dipisahkan ke dalam file `.css` tersendiri agar struktur *project* lebih rapi dan mudah dikelola (Modular).
* **Tata Letak (Layouting):** Penggunaan properti CSS untuk mengatur posisi elemen, margin, padding, serta memberikan spasi antar konten agar lebih mudah dibaca.
* **Tipografi & Warna:** Pemilihan font yang lebih modern dan skema warna yang konsisten untuk memperkuat identitas personal pada portofolio.
* **Efek Visual (Hover/Transisi):** Penambahan interaktivitas visual sederhana, seperti perubahan warna atau efek bayangan (shadow) ketika kursor diarahkan ke tombol atau tautan tertentu.

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur dasar halaman (Header, Section, Footer).
* **CSS3:** *Styling* khusus (Warna, Tipografi, Box Model, dan Layouting).

## 🚀 Cara Menjalankan Proyek

Sama seperti tugas sebelumnya, proyek ini adalah halaman web statis yang tidak memerlukan instalasi *server* lokal atau dependensi khusus.

1. *Clone* repository ini ke komputer Anda:
   ```bash
   git clone https://github.com/ValdoMilo/TugasPemrogramanWeb-Pertemuan2-Portofolio-Css.git
   ```
2. Buka folder proyek tersebut di file manager Anda.
3. Klik dua kali pada file `index.html` untuk membukanya secara langsung di *browser* (Chrome, Firefox, Safari, dll.).
